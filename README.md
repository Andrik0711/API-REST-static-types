# API REST con Tipos Estáticos

Este proyecto es una API REST construida con TypeScript y Express.

## Requisitos

Antes de comenzar, asegúrate de tener instalado lo siguiente:

- [Node.js](https://nodejs.org/) (versión 16 o superior)
- [npm](https://www.npmjs.com/) (incluido con Node.js)

## Instalación

1. Clona este repositorio:

   ```bash
   git clone https://github.com/Andrik0711/API-REST-static-types.git
   cd API-REST-static-types

2. Instala las depencias
    ```bash
    npm install express
    npm install --save-dev @types/express ts-node-dev typescript
3. Inicia el proyecto
    ```bash
    npm run dev
